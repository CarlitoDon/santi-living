# Santi Living English Blog Content (Archived Legacy)

> ⚠️ **DILARANG MENAMBAH ATAU MENGEDIT FILE ARTIKEL DI FOLDER INI!**
> 
> Seluruh artikel blog bahasa Inggris Santi Living kini dikelola 100% melalui **Notion CMS** database (`Santi Living Articles`).
> 
> - **Tambah / Edit Artikel:** Gunakan tool `santi_blog_create` atau antarmuka Notion CMS.
> - **Publish:** Gunakan `santi_blog_publish` yang langsung memicu Next.js on-demand ISR revalidation (`/api/notion/revalidate`).
> - **Git Repo:** Murni untuk kode aplikasi Next.js, bukan untuk penulisan/publikasi konten blog markdown.
